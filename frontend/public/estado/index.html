Estado del servicio

Mapa Apagones está operativo en producción, con mejora continua. Puede consultar el detalle de cambios en el changelog público.

Dominio público

El dominio público del proyecto es https://mapa-apagones.es.

Arquitectura

  • Frontend público desplegado en Cloudflare Pages.
  • API y datos dinámicos servidos desde infraestructura propia, expuestos vía Cloudflare (sin apertura de puertos públicos en el router).
  • Base de datos SQLite con reportes agregados y expiración temporal.

Estado funcional

La interfaz pública, páginas informativas, mapa y base de reportes ciudadanos siguen en evolución activa. Pueden existir cambios frecuentes de diseño, cobertura geográfica y funcionamiento; el changelog refleja los cambios reales confirmados.
