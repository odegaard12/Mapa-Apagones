Seguridad y privacidad

Ayúdanos a comunicar problemas de forma segura

Mapa Apagones es un proyecto ciudadano sin cuentas, sin CUPS y sin direcciones exactas. Las vulnerabilidades deben comunicarse de forma privada para evitar exponer usuarios, secretos o el propio servicio.

Comunicación privada

Escribe a privacidad@mapa-apagones.es con el asunto [SEGURIDAD].

Indica el componente afectado, el impacto y pasos mínimos para reproducir el problema sin incluir datos personales.

No lo publiques en una issue

No abras una issue pública con detalles explotables. No adjuntes tokens, cookies, bases de datos, backups, logs completos, CUPS, direcciones ni coordenadas privadas.

Tiempos objetivo

  • Acuse de recibo: hasta 5 días laborables.
  • Clasificación inicial: hasta 10 días laborables.
  • Los problemas críticos reciben prioridad.

Estos plazos son objetivos operativos, no garantías contractuales.

Alcance

Incluye la web, la API, el flujo anónimo de reportes, controles antiabuso, privacidad y exposición accidental de datos o secretos.

No autoriza escaneos masivos, denegación de servicio, ingeniería social ni acceso a datos de otras personas.
