# Auditorías regionales de distribuidoras

Carpeta para investigar posibles `regional_default` antes de tocar producción.

Reglas:

- No publicar CUPS.
- No publicar datos personales.
- No publicar direcciones exactas.
- No publicar coordenadas privadas.
- No publicar subestaciones, líneas, tendidos, cables, centros de transformación ni inventario de infraestructura crítica.
- No convertir presencia regional en cobertura municipal exacta.
- `regional_default_candidate` no es producción.
- Solo pasar a producción cuando el wording sea prudente y el bloque sea suficientemente defendible.
